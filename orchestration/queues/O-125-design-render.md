# O-125 케이스 디자인 재설계 + 사실적 렌더 (사용자 지시 2026-11-28)

사용자 원문: "너무 디자인이 별로고 그다음에 렌더링도 현실적이지 않아."

## lead 진단 (validation/runtime/vd001/render/blender/stills/ren002_*.png, docs/readme/gallery/mech/*.png 기준)
디자인
- 모서리가 전부 직각인 상자 + 옆에 따로 붙인 방열판 덩어리 → 제품이 아니라 시험 지그처럼 보임.
- 앞면에 투명 창 두 장 + 렌즈 구멍 + 나사 4개가 그대로 노출 → 속 PCB·글자가 비침, 정돈되지 않음.
- 비례: 방열판이 본체만큼 커서 무게중심·인상이 한쪽으로 쏠림. 설치 방식(브래킷·마운트)이 보이지 않음.
렌더
- 균일한 회색 배경·평평한 조명, 반사·환경광 없음 → CG 티.
- 메시가 각진 STL(모깎기·베벨 없음), 재질에 미세 질감 없음(플라스틱이 페인트 같음), 유리 반사·굴절 부자연, 접촉 그림자 약함.
- 렌즈·IR LED·라벨·나사 등 제품다운 작은 디테일 없음.

## 목표
"사진이라고 해도 믿을" 제품 렌더 + 보기 좋은 소형 엣지 AI 카메라 외관. 내부 제약(보드 3층 적층·광축·IR LED 창·커넥터 삽입·방열 #26)은 지킨다.

## 1단계 — 디자인 시안 3종 (빠르게, 덩어리 수준) — mechanical(t18x, Fusion 단일 작성자)
- A (추천 기본값): 모서리 R4~6 둥근 직육면체 "박스 카메라". 앞면 전체를 한 장의 IR 투과 검정 유리(아크릴)로 덮어 렌즈·IR LED·조도 센서를 감춤(속이 안 비침). 뒤쪽 1/3은 알루미늄 방열 쉘(가는 핀이 몸체 안으로 통합된 형태) + 앞 2/3는 무광 흑색 플라스틱, 두 재질 경계에 얇은 분할선. 아래 1/4" 삼각대 나사 + 벽 브래킷.
- B: 정육면체에 가까운 "퍽/큐브" — 상판 알루미늄 핀, 전면 원형 렌즈 링 강조.
- C: 원통형 "불릿" — 앞 차양(sunshield), 뒤 케이블 글랜드.
- 각 시안: 같은 내부 적층(main 995b872 보드 STEP)이 들어가는지만 덩어리로 확인(간섭 0), 시안당 30분 이내. 나사는 바닥·뒷면으로 숨김, 상태 LED 광 파이프, 케이블 출구 1곳, 앞면 하단에 작은 "OpenHW" 음각.
- 산출: 시안별 Fusion 내보내기(STEP/고해상도 STL) → 2단계 렌더 파이프라인으로 시안당 히어로 1장씩 → lead 가 사용자에게 보여 고르게 함(답이 없으면 A로 진행).

## 2단계 — 사실적 렌더 파이프라인 — schematic(t1bn, Fable, REN-003b 확장, Blender 헤드리스)
- 조명: 무료 CC0 HDRI(Poly Haven 공식 배포처, 사용자 홈 격리 폴더에 받기·sha256 기록·결제 없음) 스튜디오 + 키·림 라이트, 무한 배경(cyclorama) + 그림자 받는 바닥(shadow catcher), 접촉 그림자 또렷하게.
- 카메라: 실제 렌즈 값(85~100mm), 피사계 심도 약하게(f/5.6~8), 3분할 구도. 색 관리 AgX, 노출 보정.
- 메시: STEP → 고해상도 테셀레이션(곡면 오차 ≤0.01mm), Auto Smooth/Weighted Normal, 날카로운 모서리 0.2~0.5mm 베벨.
- 재질(PBR, ren003 재질 표 확장): 무광 흑색 플라스틱 = 미세 노이즈 범프 + 거칠기 0.45~0.55 변화, 양극산화 알루미늄 = 이방성 헤어라인, IR 투과 앞유리 = 짙은 검정 반투과 + 프레넬 반사 + 얇은 코팅감, 렌즈 = 다층 코팅 반사(보라·초록 기미), 고무 가스킷, 나사 금속, 실크 인쇄 라벨.
- 엔진: Cycles(GPU OptiX가 있으면 사용), 샘플 충분히 + 디노이즈, 4K 원본·README용 1600px 축소.
- 컷: 히어로(¾ 앞), 앞 정면, 뒤 ¾(포트·방열), 분해도(부품 간격·바닥 그림자), 단면, 사용 장면(벽 브래킷에 달린 모습, 단순한 실내 배경), 턴테이블 MP4(8~10초, 1080p).
- 지금은 현재 외함으로 파이프라인부터 완성·시험(저해상도), 시안 나오면 메시만 바꿔 렌더.

## 3단계 — 최종 (사용자 시안 선택 뒤)
- mechanical: 고른 시안을 Fusion에서 상세 설계(모깎기·분할선·나사 보스·가스킷 홈·방열 핀 계산 재확인 #26) → run_case 재판정(간섭 0·플러그 삽입·광축·LED 창) → 내보내기.
- schematic: 최종 렌더 세트 → docs/renders/final/ 대표본(VD-001 HTML 자리 이름) + README 갤러리 교체(research).
- Fusion 로컬 렌더(REN-003)는 보조(Blender가 주 렌더).

## 규칙
- 결제·유료 에셋·클라우드 렌더 금지. 무료(CC0) 에셋만, 출처·라이선스·sha256 기록.
- 특정 회사 제품 외형 복제 금지(일반적인 제품 유형만 참고).
- Fusion 단일 작성자 = mechanical. Docker 금지. 새 칸 띄우지 않음(O-112).
- 사람 눈 판정 항목(예쁨·사실감)은 verifiable 아니오 — 사용자 확인 전까지 통과 아님.
