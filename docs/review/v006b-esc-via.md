# V-006b J1 탈출 비아 완화 판정 (O-114, D-003 #60, review)

D-003 #60은 캐리어 J1(BTB 0.5 피치) 탈출 비아만 0.50/0.20(링 0.15)을 J1 둘레 규칙 영역(`enclosedByArea`) 안에서 허용한다. 그 밖은 #21의 0.65/0.30 그대로다. orch가 지시한 판정 ①~④를 감수 도구에 넣었다.

## 판정 항목 (조건 2, 모두 verifiable 예)

| id | 판정 | 기준 | 계산하는 곳 |
|---|---|---|---|
| 2.V1 | 0.65/0.30 미만 비아는 탈출 영역 안에만 (② + ① 걸침) | 영역 밖·걸친 작은 비아 0 | `v005_rules.py` 7번 `esc_vias.outside_small` |
| 2.V2 | 탈출 규칙이 `enclosedByArea`뿐 (①) | `.kicad_dru`에 `intersectsArea('J1_…')` 0, `enclosedByArea('J1_…')` 있음 | `v006_cond2.py` |
| 2.V3 | 영역 안 작은 비아 (③) | 지름 ≥0.50 · 드릴 ≥0.20 · 링 ≥0.15 · 구멍 가장자리 간격 ≥0.28 | `esc_vias.inside_fail` |
| 2.V4 | 영역 안 작은 비아는 J1 핀 넷뿐 | 다른 넷 0 | `esc_vias.non_j1_net` |
| 2.V5 | 영역이 J1 둘레 안 | 영역이 J1 외곽 상자 밖으로 ≤3.0 [가정] | `esc_vias.areas[].beyond_j1` |
| 2.RLX | 완화가 D-003 #60 기록과 맞음 (④) | 아래 대조표 | `v006_relax.py` + `relax-records.json` |

- **영역:** 이름이 `J1_`로 시작하는 규칙 영역이다(예: `J1_ESC`).
- **「영역 안」:** 비아 구리 원의 중심과 둘레 16점이 모두 영역 안이다. KiCad `enclosedByArea`와 같은 뜻이다. 일부만 걸치면 「걸침」이고 밖으로 센다.
- **구멍 간격:** 그 비아 드릴 가장자리에서 다른 모든 구멍(비아·패드 드릴) 가장자리까지의 최소 거리다.
- **V2~V5:** 영역이나 영역 안 작은 비아가 있을 때만 나온다. V1은 두 보드에 늘 나온다.

### 완화 대조 (④, `relax-records.json`)

| 규칙 조건 | D-003 행 | 그 행에 있어야 할 문구 | 보드 값 |
|---|---|---|---|
| `via_diameter` + `enclosedByArea(J1_…)` | #60 | 「0.50/0.20」, 「enclosedByArea」 | 정확히 0.50 |
| `hole_size` + `enclosedByArea(J1_…)` | #60 | 같음 | 정확히 0.20 |
| `hole_to_hole` + `enclosedByArea(J1_…)` | #60 | 「구멍 간격 {값}」 | — |

- 같은 완화를 `intersectsArea`로 쓰면 맞는 기록이 없어 「기록 없음」으로 불합격이다.
- 값이 0.50/0.20과 다르면 「기록 문구 불일치」다. 이를 위해 대조표에 `value`(정확한 값)와 `area_re`(영역 이름 정규식)를 더했다.
- 링 0.15는 제조 기준과 같아 완화가 아니다.
- **구멍 간격:** 제조 기준(`fab_hole_to_hole`)은 0.45다. pcb가 영역 안에서 0.28로 낮추는 규칙을 넣으면, D-003 #60에 「구멍 간격 0.28」이 적혀 있어야 통과한다. 지금 #60에는 이 값이 없다.
