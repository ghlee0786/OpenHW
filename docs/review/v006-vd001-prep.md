## 조건 2-① 완화 ↔ D-003 (`v006_relax.py`, 대조표 `relax-records.json`)

**완화로 보는 것**

| 키 | 내용 |
|---|---|
| P1 | `.kicad_pro` 규칙 최소값 < P-001 기준 |
| P2 | `rule_severities` = ignore |
| D1 | DRU min 제약 < 기준 |
| D2 | DRU max 제약 > 완화 전 한도(#28 앞 값 · 쌍 간격 0.18) |
| D3 | 영역 · 부품에 묶인 규칙이 기준이나 영역 밖 규칙보다 느슨함 |
| D4 | severity ignore/exclusion 규칙 |

**기록 대조 방식**
- 대조표에 「규칙 → D-003 행 번호 + 그 행에 있어야 할 문구」를 적어 두었다.
- 문구 안의 `{value}`는 지금 보드 값으로 바꿔 찾는다. 값이 바뀌면 D-003도 바뀌어야 통과한다.
- 대조표에 없는 완화는 「기록 없음」으로 불합격이다.

**지금 걸리는 완화 (690ff78)** — orch 판단이 필요하다. 둘 중 하나를 고른다.
- D-003에 기록을 더하고 그 줄을 `relax-records.json`에 넣는다.
- pcb가 규칙을 되돌린다.

| 완화 | 두 보드 | 내용 | 제안 |
|---|---|---|---|
| ignore 5종 | 둘 다 | `footprint_filters_mismatch` · `footprint_type_mismatch` · `missing_courtyard` · `track_not_centered_on_via` · `tuning_profile_track_geometries` | ignore 이유를 D-003에 적거나 warning으로 되돌린다(`--severity-all`이면 warning도 센다) |
| `csi_100_pair` · `mdi_100_pair` track_width min 0.14 | 둘 다 | P-001 · D-003 #21 트랙 0.15보다 느슨하다(실제 트랙은 0.15) | 0.15로 올리는 것이 쉬움 |
| `dp_breakout_pair` 쌍 간격 max 2.2 · `dp_breakout_spacing` 0.16 (DP_BRK) | 둘 다 | 커넥터 · ESD 탈출 구역 예외 — D-003 기록 없음 | D-003에 기록(예: #28 옆) |
| `dp_tuning_gap` 쌍 간격 max 1.0 (DP_TUNE) | 둘 다 | 쌍 안 보정 굴곡 구역 예외 — 기록 없음 | 같음 |
| `u2_htssop_thermal_vias` 구멍 0.20 | 캐리어 | U2 열 비아 Ø0.2 < 0.30 — 기록 없음(P-001 §6 견적 확인 대상) | D-003에 기록 |

기록 일치: #28 비결합(CSI 3→4 · MDI 5→6 · USB 5→12), #31 꼬임 예외(DP_TWIST 3규칙).
