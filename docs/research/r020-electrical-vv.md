## 0. 결론

**이 커밋은 배선 중이다. 판정 행 43개 가운데 35행을 판정했고 그중 7행이 불합격이다. 나머지 8행은 미배선이라 판정하지 않았다.** `ev_check.py` 종료 코드는 **7**이다.

1. **① 임피던스는 6쌍 모두 ±10% 안이다(계산).**
   - 결합 구간의 실측은 선폭 0.150(USB 0.200), 간격 0.170mm 한 값뿐이다.
   - IPC-2141A 식에 솔더마스크 −8Ω을 적용하면 CSI·MDI는 **102.6Ω**(목표 100), USB는 **89.7Ω**(목표 90)이다.
   - 이 값은 V-005 A6과 같다. P-001 유한차분과의 차이는 −0.4 / −3.1Ω이다.
   - 마스크를 빼면 CSI·MDI는 110.6Ω(+10.6%)이 되어 한도 밖이다. 즉 이 통과는 마스크 보정에 기대고 있다.
2. **② 차동쌍은 불합격 4건이다.**
   - 쌍 안 길이 차: MDI_TX 0.580mm, MDI_RX 7.223mm, USB 8.607mm. 한도는 D-003 #28의 「0」이다. 비아 높이를 넣으면 0.926 / 10.235 / 11.619mm로 더 커진다.
   - USB 비결합 길이 28.80mm. 한도는 12mm이고, 비아 높이를 넣으면 33.32mm다.
   - CSI 3쌍은 모두 통과한다. 쌍 안 차 0.000, 레인 skew 0.000, 비결합 3.88 / 3.61 / 3.08mm(한도 4)이다.
   - MDI 비결합도 통과한다. 꼬임 영역 밖은 TX 4.73, RX 5.61mm(+비아, 한도 6)다. 꼬임 영역을 포함한 전체는 9.96 / 14.99mm(한도 20)다.
3. **③ 전원은 불합격 3건이다.** 기준은 IPC-2152 곡선 맞춤, ΔT 10K다.
   - **캐리어 5V_SYS:** 벅(L1)에서 BTB까지 주 경로가 0.30mm 선 약 8mm로 이어진다. 1.3A가 모두 이 선으로 흐른다. 허용 전류는 1.03A이고, 1.3A에서 ΔT는 16.6K다.
   - **캐리어 12V_IN_F:** F1에서 Q1 사이에 Ø0.40 비아 2개가 직렬로, 병렬 없이 놓여 있다. 1.84A가 흐르는데 비아 하나의 허용 전류는 1.81A다(−1.6%).
   - **전면 CORE_3V3:** Q2로 가는 0.15mm 선을 공급 상한 1.0A로 판정했다. 허용 전류는 0.70A다. 계약에 센서 부하 수치가 없어서 상한값을 썼다. 계약이 0.70A 이하로 정해지면 통과한다.
   - 12V_IN_RAW, 캐리어·전면 12V_IR, CAM_1V8은 통과다.
   - 경로 저항·강하는 모두 47mV 이하다(50°C 구리 기준).
4. **④ 열은 다시 계산하지 않았다.** 모든 값은 기구 레인 커밋에서 인용했다.
   - M-003 2차(4752a68): H3 방열판 5.6K/W, 안 공기 상승 19.8K, 40°C에서 SoC 69.0°C · LED 76.0°C(A+B).
   - M-005(f1a53e4): SK 444를 71mm로 자른 안은 8.4K/W다(목표 8 미달, +4%). 안 공기 상승은 21.8K다.
   - 두 커밋 모두 아직 main에 없다(브랜치 `harness/t-20261127-013549-8089`).
5. **고장 주입 시험 4건이 모두 기대대로 나왔다.** `run_fault_tests.py`의 종료 코드는 0이다.
   - 전원선을 좁히면 +1, CSI 선폭을 바꾸면 +1, 두 가지를 동시에 하면 +2다.
   - 전원 넷 트랙을 삭제하면 종료 코드는 그대로이고 「미배선」으로 따로 센다. 스크립트는 멈추지 않는다.
6. **배선이 끝난 커밋에서 같은 명령으로 다시 돌려야 확정된다(§7).** 현재 미연결은 캐리어 21건, 전면 37건이다(KiCad).

## 2. 방법과 식

| 항목 | 식·처리 | 출처 |
|---|---|---|
| 임피던스(외층) | Z0 = 87/√(εr+1.41)·ln(5.98h/(0.8w+t)), Zdiff = 2·Z0·(1 − 0.48·e^(−0.96·s/h)). h·εr·t는 보드 stackup에서 신호층과 인접 구리층 사이 유전체로 읽는다(F.Cu → dielectric 1 = 0.1855/4.74, B.Cu → dielectric 3) | IPC-2141A edge-coupled microstrip. 공개 재현: https://www.nextpcb.com/differential-microstrip-impedance-calculator |
| 임피던스(내층) | 스트립라인 Z0 = 60/√εr·ln(1.9b/(0.8w+t)), Zdiff = 2Z0(1 − 0.347e^(−2.9s/b)). 실제로는 쓰이지 않았다. 고속선은 내층에 없다(`hs_outer_only`) | IPC-2141A |
| 솔더마스크 보정 | Zdiff −8Ω, 단선 −2Ω(1회 인쇄) | PCBWay Impedance Control 「printing one pass of solder mask reduces single-ended impedance by 2 ohms and differential impedance by 8 ohms」 https://www.pcbway.com/pcb_prototype/Impedance_Control.html (2026-11-27 확인). 교차 확인: P-001 유한차분 마스크 0.015/εr3.5 효과 −10.4Ω(0.15/0.16), −8.5Ω(0.20/0.16) |
| 쌍 간격 실측 | 같은 층에서 P 선분마다 평행(±1°)한 N 선분을 찾고 축에 투영해 겹친 구간을 잡는다. 간격은 가장자리 사이 = 중심 간 수직거리 − (wP+wN)/2. 겹친 구간을 잘게 나눠 각 조각에서 가장 작은 간격을 쓴다. 간격 ≤0.18mm(DRU `diff_pair_gap` max)이면 결합, 나머지는 비결합이다 | V-005 A10과 같은 정의 |
| 비아 높이 | 비아에서 그 넷 트랙·패드가 닿는 가장 바깥 두 구리층 중심 사이 z 거리. F↔B = 1.506mm(stackup). 비결합(+비아)에는 상대 넷 비아가 1.2mm 안에 없는 「짝 없는 비아」의 높이만 더한다 | 보드 stackup |
| 레인 skew | \|레인 평균(P,N) 길이 − CLK 평균 길이\|. 트랙만 잰 값과 +비아 값 둘 다 판정한다 | D-003 #28, DRU `skew` |
| 트랙 허용 전류 | IPC-2152 Figure 5-2 범용 곡선 맞춤: A[mil²] = (117.555·ΔT^−0.913 + 1.15)·I^(0.84·ΔT^−0.108 + 1.159). 이것을 역으로 풀어 I를 구한다. 수정계수(구리 두께·판 두께·인접 면·열전도)는 **적용하지 않았다**. 차트 기준은 폴리이미드 0.070"·3oz·정지 공기·면 없음이라 In1 GND가 0.19mm 아래 있는 이 보드에는 보수 쪽이다. 참고로 IPC-2221 I = k·ΔT^0.44·A^0.725(k 0.048 외층 / 0.024 내층)를 나란히 적었다 | https://smps.us/pcb-calculator.html (예제 10A·ΔT20 → 513mil², 시험으로 재현). IPC-2221 식은 netclasses.md §3.1과 같다 |
| 구리 두께 | 보드 stackup 0.035mm(외층 0.5oz+도금 = 완성 1oz, 내층 1oz) | P-001 §2.1 |
| 비아 허용 전류 | 도금 원통 단면 A = π·t·(d−t), t = 25µm, d = 보드의 드릴(0.30 / 0.40mm). 이 A에 위 IPC-2152 식을 적용했다(트랙과 같은 단면이면 같은 전류). 결과: Ø0.30 → 1.53A, Ø0.40 → 1.81A. 참고로 IPC-2221 내층식은 0.84 / 1.06A다 | 지시(25µm) · IPC-6012 Class 2 평균 20µm이면 Ø0.40 허용 약 1.60A |
| 전류 분포 | 넷마다 트랙·비아·패드·구리면을 저항망으로 만들고 직류 절점 해석을 한다. 소스 패드 묶음 하나를 0V로 두고 싱크 묶음마다 전류를 뽑는다. 선마다 흐르는 전류 ≤ 그 선폭의 허용 전류인지 판정하고, 비아도 같다. 싱크별 전류가 계약에 있으면 동시 해석(12V_IN 1.22/0.62, 전면 12V_IR 0.61/0.61, 전면 VIN 0.245/0.03), 없으면 묶음마다 전체 전류로 풀어 선별 최댓값을 쓴다(보수 포락) | ρCu 1.724e−8Ω·m(20°C), α 0.00393/K. 강하는 50°C(40°C 주위 + 10K) 구리 기준 |
| 미배선 | 넷 패드들이 저항망에서 몇 덩어리로 나뉘는지 센다(덩어리 − 1 = 미연결). 덩어리가 둘 이상인 넷의 항목은 「미배선」으로 따로 세고 종료 코드에 넣지 않는다. 구리면 넷(GND 등)을 뺀 합계가 KiCad 연결성(`GetUnconnectedCount`)·DRC JSON(6ecfa85)과 넷마다 같다: 캐리어 17 = 21 − GND 4, 전면 7 = 37 − GND 30 | — |
