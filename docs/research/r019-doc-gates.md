- **FW 조건:**
  1. 핀먹스를 PWR_GPIO_8(기능 3, gpio360)로 바꾼다.
  2. `RTC_EN_7SEC_RST`=0을 유지한다.
  3. 꺼진 상태에서 INT Low가 켜기 원인이 되는 것이 싫으면 `RTC_EN_PWR_UP` bit12를 끈다(상시 켜진 카메라라 영향은 작다).
- **차선 핀:** SPARE1(캐리어 20, MIPI_TXM1 → XGPIOC_14 gpio430, 1.8V 일반 GPIO, 같은 GH 하니스 4번, 계약 L416).

## 3. 첫 PCBA bring-up으로 넘기는 항목

1. BTB 결합 뒤 판 사이 간격 실측(8.0 ±0.15), HCTL↔SUNGTECH 끼움·탈착, 1·2·59·60 도통
2. 5V_SYS 피크(ICR 펄스 + IR 켬) 때 BTB 전압 강하·온도
3. BXF4677 블록 두께, 강판 외곽(귀), CLA216 공동 깊이, DF30 결합 높이 → `ped_h`·`sp_t` 재계산
4. 영상 중심 vs 광축
