# R-007 기구 도면 수치 확보 (M-001c 미확인 해소용)

- 배정: orch t18r R-007 · 대상: mechanical M-001c `mechanical/stack-reference.md` (레인 t-20261126-161155-50dc, 커밋 4dc801d)의 「미확인」 수치
- 조사자: research t18s · 확인일 **모두 2026-11-26** · 공개 자료만 사용(로그인·이메일 입력·견적·문의 없음)
- 표기:
  - **확인됨**: 도면·표에 치수가 기입돼 있다
  - **판독**: 도면 이미지에서 픽셀 배율로 잰 값. 배율은 도면에 기입된 치수로 교차 확인했다
  - **계산**: 확인된 값으로 계산했다
  - **미확인**: 근거를 찾지 못했다
- 열람 불가 기록:
  - 이메일·로그인을 요구한 곳은 없었다.
  - Mouser DF30 카탈로그(HTML 차단), hirose.com(404/403), LCSC C5182372 데이터시트(스크립트 리디렉트)는 받지 못했다.
  - commonlands.com 본 사이트 대신 같은 Shopify CDN 원본 도면을 썼다.

- **해석 (공동 깊이):** 공동 깊이 약 1.2보다 센서 블록과 받침의 높이 합이 크면 CLA216 바닥이 블록에 닿는다.
  - 받침 두께는 공동 깊이 안에서 정한다. M-001c 받침 0.75 + 블록 두께(강판 0.4 + FPC 0.12 + CSP 0.76 = 1.28) = 2.03 > 1.2 → **간섭 가능성. 홀더 아래 스페이서가 필요할 수 있다**(M-001c K12 차선과 연결).
  - 판단은 mechanical이 한다.

## 확인 못 한 것

- CLA216: 공동 깊이(판독뿐), 고정 나사 규격, 리드 길이
- CIL093: 나사 길이와 시작 위치(치수 기입이 없어 판독뿐)
- OK-04AM024-04: 제조사, 결합 높이, DF30 호환
- DF30FC-24DP: 실재 여부
- BXF4677: 강판 외곽(귀 포함 여부), CSP 센서 높이(GC2053 CSP 가이드 0.76은 R-006 근거)
- 근거 파일 위치: 이번에 받은 근거 파일(도면 원본 webp, Vishay 80294 PDF)은 세션 임시 폴더에만 있다. 제조사 저작물이라 저장소에 보관하지 않는다(D-003 #14).
