# M-001 기구 기준 형상 (적층·광축)

- 배정: orch t18r M-001 (+보충 ①J1/J2 독립 판정 ②렌즈 몸체 미정) · M-001b 갱신(짝 BTB 높이 8.0, DF30 자리 변수) · M-001c 갱신(R-006 렌즈 CIL093·IR LED 4개·센서 블록 받침) · M-001d 갱신(R-007 도면 수치, 받침–홀더 공동 간섭 해소) · 작성: mechanical t18x · 날짜 2026-11-26
- 범위: 3층(캐리어–코어–전면 보드) 적층 기준과 광축 기준. **외함 설계 아님.**
- 레인: t-20261126-161155-50dc · Fusion 단일 작성자 = mechanical
- 표기: **측정** = Fusion에서 STEP 형상을 스크립트로 읽은 값 · **가정** = 근거 없이 정한 기본값 · **미확인** = 데이터시트·실물 확인 필요

## 0. 좌표·단위 정의

- 단위 mm.
- **원점 O = 코어 보드 외형 중심, 코어 PCB 아랫면(J2 쪽)**.
  - Seeed STEP 좌표로는 (60.0, −65.0, 0.0)이다.
- **+Z = 코어 윗면(J1·SoC 쪽) = 전면(센서·피사체 쪽) = 광축 방향.**
- X·Y 축은 Seeed STEP과 같다(회전 없음, 평행이동만).
- 아래 좌표는 모두 O 기준이다. Seeed STEP 원좌표로 바꾸려면 (x+60, y−65, z)를 쓴다.

### 3.1 받침–홀더 공동 간섭: 선택지 계산 (전면 보드 윗면 기준 높이, 단위 mm)

- **조건식.** 받침 p, 홀더 바닥(스페이서) s로 둔다.
  - ① 공동: 블록 윗면 p + 1.28 ≤ s + cav_d(1.2) − 0.1 → **s − p ≥ 0.18**
  - ② FPC가 홀더 벽 아래를 지남 (FPC 윗면 p + 0.52): s ≥ p + 0.52 + 0.1 → **s − p ≥ 0.62**
  - ③ 초점 (렌즈 뒤끝 = 상면 + MBFL ≥ 홀더 바닥 + 최소 MBFL 2.85, 최악 MBFL 2.9): p + 0.835 + 2.9 ≥ s + 2.85 → **s − p ≤ 0.885** (공칭 MBFL 3.2면 ≤ 1.185)
  - ④ FPC 평평 (DF30 결합 0.9 + 보강판 0.25 = FPC 아랫면 1.15 = p + 0.4): **p = 0.75**
- **M-001c 상태 (p 0.75, s 0):** s − p = −0.75 → ①·② 위반. 이것이 orch 지적과 같은 문제다.

| 안 | p | s | ① 공동 (≥0.18) | ② FPC (≥0.62) | ③ 초점 (≤0.885) | ④ FPC 평평 | 추가 공정 | 판정 |
|---|---|---|---|---|---|---|---|---|
| (a) orch 원안: 받침 0 + 스페이서 | 0 | 0.3~0.885 | ○ | **×** (FPC가 0.4→1.15로 올라가며 벽 높이에서 지나감 → s ≥ 1.27 필요한데 ③과 충돌) | ○ | × (0.75 휨) | 스페이서 | 불가 (홀더 벽에 FPC 홈을 파야 함) |
| **(a′) 받침 0.75 유지 + 스페이서 1.5** | **0.75** | **1.5** | ○ 여유 0.57 | ○ 여유 0.13 (FPC 윗면 12.47 ↔ 홀더 바닥 12.7: 0.23) | ○ 최악 여유 0.135 / 공칭 0.435 | ○ | 스페이서 프레임 1장 (나사 공용) | **1안** |
| (b) 전면 보드 카운터보어 (깊이 d) + 받침 0 | −d | 0 | d ≥ 0.18이면 ○ | × (FPC가 −d+0.4에서 1.15로 휨, 벽 통과 불가) | ○ | × 휨 커짐 | 깊이 제어 밀링 (PoC 저가 공정 밖, P-001 확인 필요) | 기각 |
| (c) FPC·DF30 재배치 (DF30을 블록 높이로 낮춤) | 0 | — | — | DF30 리셉터클을 카운터보어에 넣어야 함 | — | — | 밀링 + 실장 위험 | 기각 |

- **결론:** (a′)를 고른다.
  - 받침 0.75로 FPC를 평평하게 두고, 홀더를 1.5 스페이서 프레임 위에 올린다.
  - 그러면 ①②③④가 모두 성립한다.
- **가능 범위:** s ∈ [p + 0.62, p + 0.885] = **[1.37, 1.635]**. 1.5는 이 범위의 가운데다.
- **G2 실측으로 다시 맞출 값:** cav_d(1.25면 ① 여유 +0.05), DF30 결합 높이(바뀌면 p = 결합 + 0.25 − 0.4로 다시 계산), 블록 두께.

#### 3.2.1 CLA216 리드(JST 1.25 2P) 출구

- 코일 하우징을 **+X**에 둔다(외형 X −7.95…+12.35).

  - 광차단 칼라는 z 38.8 이상에 있다.
  - LED와는 최소 4.3 떨어져 있다.
  - 적층 나사 (13, ±13)에서 2 이상 떨어져 있다.

### 3.3 광차단 안 (갱신) 과 창 거리

- **칼라 방식으로 변경:**
  - 렌즈 금속 경통 자체가 불투명하므로 빛을 막아야 할 곳은 앞 유리(돔) 둘레뿐이다.
  - 그래서 M-001c의 「홀더 윗면 ↔ 창」 긴 링(ID 16 / OD 22, 높이 11.7)을 없앴다.
  - 대신 **렌즈 머리 앞면 위 흑색 폼 칼라**(ID 14 / OD 20, 높이 1.9 = 돔 1.4 + 틈 0.5, 압축 전 약 2.5 가정)를 창 안쪽 면에 압착한다.
- **창 안쪽 면 반사:** LED는 칼라 밖, 돔은 칼라 안에 있다 → 정반사 경로가 칼라 벽을 지나므로 막힌다. 칼라 아래쪽은 머리 Ø18 금속이 가린다.
- **창 바깥 면 1회 반사 밀림 2.9:** 칼라 벽 3.0(= (20 − 14)/2)으로 덮는다.
- **화각 비네팅 조건 (계산):**
  - 돔 가장자리 반경을 r_g라 하면, 창 안쪽(돔 바닥에서 1.9 위)에서 화각 반경은 r_g + 1.9 × tan48° = r_g + 2.11이다.
  - 칼라 ID 반경 7.0에서 여유 0.3을 빼면 **r_g ≤ 4.59 (돔 Ø9.2 이하)** 가 필요하다.
  - 돔 지름은 **미확인**이다(R-007에도 없음). 크면 칼라 ID를 키우고 OD를 22로 올린다(차선 K16).
- **창 거리:** 창 안쪽 z = 전면 윗면 11.2 + 받침 0.75 + 0.835 + TTL 27.4 + 0.5 = **40.685**. 상면 기준으로는 27.9다.
- **창 투과 개구(불투명 앞판):** 반경 ≥ 화각 반경 + 0.5. 돔 Ø10 자리값이면 반경 ≥ 7.6이다.

### 3.5 간섭 검사 (Fusion `analyzeInterference`, 맞닿는 면 제외) — M-001d
