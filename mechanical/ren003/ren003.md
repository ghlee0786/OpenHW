# REN-003 Fusion 재질 · 로컬 렌더 (준비만 — 실행은 KiCad 완료 알림 뒤)

- 상태: **코드와 문서만 준비했다. Fusion은 열지 않았다.** D-003 #53 · orch 정정: Fusion 작업은 KiCad가 끝난 뒤에 한다(DRC 0 · 미연결 0 · V-006 · P-004 · STEP 내보내기).
- 실행하지 않은 것:
  - Fusion 스크립트 01~03 (`mechanical/ren003/scripts/`)
  - `run_ren003.py`
  - Blender 렌더
- 시험한 것:
  - 재질 규칙 건식 점검 `python -I -B mechanical/ren003/dryrun_glb.py` → **rc 0**. 보드 GLB 2장(pcb 6df2865 · be3125d 사본), 색·모델 조합 120가지 중 못 가른 색 0. 표는 `assign_glb.md`.
  - 모든 바꾼 파일 구문 검사.
- 만료 주의: Fusion 창에 「4일 후 만료」가 떠 있다. 만료되면 D-003 #34 차선(CadQuery + Blender)으로 간다. Blender 쪽은 같은 재질 표를 이미 쓴다.

## 1. 흐름 (실행 때)

```
python -I -B mechanical/m010/run_case.py --pcb-carrier <커밋> --pcb-front <커밋>    # 보드 STEP·판정·M007 문서·Blender 렌더 (재질 표 적용)
python -I -B mechanical/ren003/run_ren003.py                                          # Fusion 재질·로컬 렌더 6장
```

`run_ren003.py`는 다음 순서로 돈다.

1. 렌더용 보드 STEP을 만든다(층 포함: `--include-tracks/pads/zones/silkscreen/soldermask`, `--user-origin 100x100mm`).
   - 입력은 `pcbsrc/<보드>`(3D 모델 연결 사본)이고, 출력은 `render/fusion/boards/<보드>_render.step`이다.
   - 판정용 `boards/*.step`(층 없음)과는 따로 둔다.
2. M007 문서를 활성으로 한다.
3. `01_render_boards.py`: 렌더용 보드를 `REN_CARRIER`/`REN_FRONT`로 가져와 판 아랫면 z에 놓는다. 판정용 `REF_*`는 숨긴다.
4. `02_appearance.py`: 재질 표로 Appearance를 배정한다. 배정 결과는 `render/fusion/appearance.json`에 남긴다.
5. `03_render.py`: **로컬 렌더만**(`startLocalRender`) 쓴다.
   - 보기: front · back · threequarter · exploded · window · connectors, 2560×1440.
   - 클라우드 렌더와 크레딧은 쓰지 않는다. API가 없으면 멈춘다(뷰포트 캡처를 렌더라 부르지 않는다).
6. 확인과 기록:
   - 파일과 해상도를 확인한다.
   - `render/manifest.json`에 `product-fusion` 항목을 넣는다(verifiable 아니오 + check 열).
   - 대표본을 `docs/renders/fusion/`에 복사한다(파일마다 20 MB 미만).
- 보관 (O-100):
  - main 체크아웃 `validation/runtime/vd001/render/fusion/`과 `render/blender/`. 이번에 Blender 스틸, 턴테이블, MP4를 `render/stills` → `render/blender/`로 옮겼다(scene · 04_dims · judge · run_case 경로).
  - PCB 렌더(`render/pcb`), 메시, manifest는 지금 자리에 둔다.

## 3. 이름 규칙 (재현 순서)

| 순서 | 규칙 | 표 | 적용 대상 |
|---|---|---|---|
| 1 | 외함·기구 이름 부분 일치 | `NAME_RULES` (HOUSING→petg, HS_EXTRUSION→anod, PMMA→pmma, FOAM→foam, INS_PADS/GAP_PAD→pad …) | Fusion 컴포넌트·바디 이름 · Blender 메시 객체 이름 |
| 2 | 보드 층 이름 `<보드>_<층>` | `LAYER_RULES`: soldermask→mask, silkscreen→silk, pad→enig, copper·via→copper(마스크 밑), PCB→fr4 | GLB 메시 이름에서 확인함. Fusion STEP 층 바디 이름은 **미확인** |
| 3 | 모델 + 색 덮어쓰기 | `COLOR_OVERRIDES`: JST 하우징 0.777→conn_white, DM3AT 0.221→shield · 0.019→conn_black, SRN/SRP 권선→copper | 같은 모델 안에서 부분을 가른다 |
| 4 | KiCad 색 분류 | `classify()`: 반투명 녹색→mask, 반투명 흰색→silk, 금속→enig, 판 색→fr4, 금색→gold, 밝은 무채색→tin, 어두운 색→몸체 | 부품 바디 |
| 5 | 몸체 → 부품 규칙 | `PART_RULES`(모델 이름 정규식이 먼저, 참조 번호는 차선): RJ45/USB-C/microSD→shield, BTB/DF30→conn_black, JST→conn_white, M12 홀더→holder, VSMA→led, LED_0603→led_smd, C_→ceramic, CP_Elec→plastic, L_/SRP/SRN→ferrite, IC·다이오드·저항·수정→epoxy | 부품 몸체 |

- Blender: `scene.py`가 `materials.py`를 읽는다.
  - 외함은 1번 규칙, 보드 GLB는 2~5번 규칙을 쓴다.
  - **GLB 재질 원값은 `glb_materials()`로 파일에서 읽는다.** glTF는 metallicFactor가 없으면 기본값이 1이라 Blender는 부품을 금속으로 읽는다.
  - 건식 점검과 같은 함수 `body_key()`를 쓴다.
- Fusion: `02_appearance.py`가 같은 `body_key()` / `name_key()`를 쓴다.
  - 모델 이름은 바디를 가진 컴포넌트 이름이다(KiCad STEP은 모델 파일 이름으로 컴포넌트를 만든다. M-010에서 확인).
  - 색은 STEP 외관 색이다.

## 4. 바뀐 것 · 분기점

| 분기점 | 고른 것 | 이유 | 차선 |
|---|---|---|---|
| 재질 표 위치 | `mechanical/ren003/materials.py` 한 곳(순수 Python). Fusion·Blender·건식 점검이 `exec`로 읽는다 | 「색·거칠기 값 표 공유」 지시. CAD와 렌더러에 매이지 않는다 | Fusion 외관 라이브러리 파일로 내보내기 |
| 보드 재질 배정 | 층 이름 → 모델+색 → 색 분류 → 부품 규칙 | KiCad GLB 재질 이름은 `mat_N`뿐이다. REN-002의 `mask/silk/copper` 이름 규칙은 맞은 적이 없어 KiCad 색이 그대로 나왔다 | 부품마다 손으로 배정 |
| 마스크 밑 동박·비아 | `copper`(ENIG 아님) | ENIG는 노출 패드에만 입힌다 | 모두 enig |
| Blender 출력 자리 | `render/blender/{stills, turntable, turntable.blend, ren002_turntable.mp4}` | O-100 지시 `render/fusion/·blender/` | 그대로 `render/stills` |
| Fusion 렌더 보드 | 층 포함 STEP을 따로 가져온다 | 판정용 STEP은 층이 없어 마스크·실크·패드가 안 보인다. 판정 문서는 run_all이 새로 만든다 | 판정 STEP에 층 넣기 (판정 바디 수·시간 늘어남) |

## 5. 확인 · 가정 · 미확인

- 확인:
  - GLB 층 메시 이름(`carrier_pad` 등), 부품 메시 이름 = KiCad 모델, 부모 노드 = 참조 번호.
  - 건식 점검 rc 0.
  - REN-002 기존 재질 키 24개가 표에 모두 있다(scene.py에서 쓰는 키 대조).
- 가정:
  - KiCad 회색 금속(0.5) 「pad」 = 노출 패드 → ENIG.
  - IC 1번 핀 표시 갈색(0.435)은 몸체로 셈.
  - PETG 무광 값은 REN-002 그대로 둠(lead 예시 ABS/PC 무광과 같은 무리).
- 미확인 (첫 실행 때 확인):
  - Fusion 로컬 렌더 API 이름(`renderManager` · `rendering.startLocalRender` · `LocalRenderStates`). 실행 전에 `fusion_cli.py docs RenderManager`로 본다.
  - Prism 외관의 거칠기 속성 id.
  - Fusion STEP 층 바디 이름.
  - 만료 전에 끝낼 수 있는지.
