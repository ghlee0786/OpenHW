# REN-001 최종 3D 렌더 (VD-001)

- 배정: orch t18r REN-001 · 레인 t-20261127-040816-30c6 · mechanical t18x · 2026-11-27
- 입력: M-007 조립 (pcb 3012bf3, M-008 CLA216·DF30, **J5 V4 B 창 연장 포함**) — `python -I -B mechanical/m007/run_all.py --pcb 3012bf3`
- 산출: `validation/runtime/vd001/render/` (gitignore). 해시 목록은 `mechanical/ren001/hashes.md`(커밋)와 `render/manifest.json`(VD-001 형식 §4)에 있다.
- 판정: `python -I -B mechanical/ren001/judge.py` — 종료 코드 = 불합격 수.
  - 파일 수: PCB 6 + 제품 6 + MP4 1
  - PNG 해상도: 2560×1440
  - MP4 길이: 7.5~8.5 s
  - 입력 해시: 조립 STEP · 보드 .kicad_pcb · 메시 index · 보드 GLB
  - **보기(색·재질·구도·겹침)는 사람 확인(verifiable 아니오)이다** → VD-001 HTML에서 체크한다.

## 순서 (모두 무료 도구 · 로컬)

| # | 명령 | 하는 일 |
|---|---|---|
| 1 | `python -B mechanical/ren001/scripts/00_pcb_render.py` (= `kicad-cli pcb render --quality high --floor --perspective --side top/bottom [--rotate -40,0,30 --zoom 0.8]`) | 보드 2장 × 윗면·아랫면·기울임 → `render/pcb/<보드>_<top/bottom/tilt>.png`. kicad-cli는 요청보다 8~32 px 작게 저장한다(2560×1440 → 2552×1432, judge 불합격 6으로 잡힘). 그래서 40 px 크게 그린 뒤 가운데를 잘라 낸다(배율 그대로) |
| 2 | `fusion_cli run mechanical/ren001/scripts/01_export_meshes.py` | M007_assembly 문서 → 부품별 STL (보드 제외, 숨김·판정 블록 제외) `render/mesh/` |
| 3 | `kicad-cli pcb export glb --drill-origin --subst-models --include-tracks/pads/zones/silkscreen/soldermask` | 보드 GLB (부품 3D·동박·실크·마스크) `render/mesh/board_<보드>.glb`. **출력 경로는 절대 경로로 준다** — 상대 경로는 rc −1, 파일 없음 |
| 4 | `blender -b --factory-startup --python mechanical/ren001/scene.py -- --mode stills` | Cycles OptiX 256 spp, 2560×1440 — 앞 · 뒤 · 3/4 · 분해 · 단면(x = 0, 불리언) · 창 근접(렌즈 창 + LED A 창) → `render/stills/ren001_*.png` |
| 5 | `... scene.py -- --mode blend` → `render_chunks.py --blend render/turntable.blend --start 1 --end 200 --chunk 50 --mp4 render/ren001_turntable.mp4` | EEVEE 1920×1080, 200프레임 @ 25 fps = 8 s, libx264 (`--fps 25` 필수 — 기본 30이면 6.67 s로 judge 불합격, 실제로 한 번 잡힘) |
| 6 | `python -I -B mechanical/ren001/judge.py` | 판정 + manifest + hashes.md |

| 폼 · P340 패드 · 스탠드오프 · 하니스 | 흑색 폼 · 보라 패드 · 황동 · 적/흑/황 전선 |

## 분기점

| 분기점 | 고른 것 | 이유 | 차선 |
|---|---|---|---|
| STEP → 메시 | Fusion STL 내보내기(부품별) + KiCad GLB(보드) | Fusion 조립 문서가 이미 판정 기준이다. GLB는 보드 층별 재질 슬롯이 있어 마스크·실크·ENIG를 따로 줄 수 있다 | FreeCAD/OCC STEP → 메시 (설치 필요) |
| 엔진 | 정지 Cycles 256 spp / 턴테이블 EEVEE 64 | 정지는 투명 PMMA 굴절·반사 품질, 턴테이블은 시간 (200프레임 약 2분) | 턴테이블도 Cycles (약 10배 시간) |
| 단면 | Blender 불리언(EXACT)으로 x > 0 반을 잘라 냄 | 렌더 안에서 끝나고 재질이 그대로다 | Fusion 단면 해석 캡처 (M-007 render_m007/) |
| 창 근접 컷 | 렌즈 창 + A 창 앞 위 비스듬히 (LED A1·A2와 PCB가 PMMA 너머로 보임) | "렌즈·LED가 창 너머로 보이는 컷" 지시 | 렌즈 축 정면 근접 (LED가 안 보여 버림) |

## 확인 · 가정 · 미확인

- **확인 (기계):** 파일 수 · 해상도 · MP4 길이 · 입력 해시. 결과는 `judge.py`의 종료 코드와 hashes.md에 있다.
- **사람 확인 (verifiable 아니오):** 재질 색 · 반사 · 구도 · 부품 겹침이 실제처럼 보이는지 → VD-001 HTML 렌더 칸.
- **가정:**
  - 3D 모델 빠짐: 캐리어 Q3·Q4·L1(+2) · 전면 X1·Q3·Q5·Q7이 렌더에서 빠져 있다(pcb가 `mechanical/models/*.step`을 아직 연결하지 않음, M-007 §1).
  - 코어 모듈은 외형 덩어리다(Seeed 형상 없음).
