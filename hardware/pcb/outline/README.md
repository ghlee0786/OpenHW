# P-002 캐리어·전면 보드 외형 템플릿

- 작성: pcb (t18v) · 2026-11-26 · 레인 t-20261126-163344-acdf
- 내용: 보드 외형, 장착 구멍, 구리 금지 영역, 커넥터 자리, 높이 제한 표시만 들어 있다. 부품·넷·배선은 없다. 회로도 넷리스트는 C-002 뒤에 들어온다.
- 좌표 근거: M-001/M-001b `mechanical/stack-reference.md` (레인 t-20261126-161155-50dc, 커밋 fd9ed82) §3.2. btb_h는 8.0이다.
- KiCad GUI는 열지 않았다. `gen_templates.py`로 파일을 만들고 `kicad-cli`로 검사·내보내기를 했다.

| `carrier/carrier-drc.json` · `front/front-drc.json` | kicad-cli DRC 보고서 |

## 2. 좌표

- M-001 원점 O(코어 중심)는 KiCad 좌표 (100, 100)이고, 보조 원점과 격자 원점도 여기다.
- 변환식은 KiCad (x, y) = (100 + x, 100 − y)다. KiCad는 Y가 아래로 늘어난다.
- 두 보드 모두 F면이 +Z(광축 쪽)를 향한다.
  - 캐리어 F면: 코어 쪽, 짝 플러그 A
  - 전면 B면: 코어 쪽, 짝 소켓 B
- DXF는 `--use-drill-origin`으로 내보냈다. 그래서 M-001 좌표와 같다.
- DXF를 파싱해 보니 외곽은 x·y 모두 −20…+20이고, 구멍은 (13,13), (13,−13), (−13,13), (−17,−17)에 Ø1.8로 있다(두 보드 동일).

## 7. 분기점

| # | 분기점 | 선택 | 이유 | 차선책 |
|---|---|---|---|---|
| O-1 | 외형 파일 형식 | KiCad 템플릿(.kicad_pcb)을 원본으로, DXF는 kicad-cli 산출물 | 규칙·적층·넷클래스가 같은 파일에 함께 있다. DXF는 기구 교환용 | DXF 원본 → KiCad 가져오기 |
