## ③ 판정 기준

**합격 조건 (개선):**
- **G1 (L3 원래 항목, 같은 측정):** A+B Rs 전류 \|I\| 최대, 끔 가장자리 100 µs 뒤 ~ 다음 켬 전 구간에서 ≤ 1 mA. 기준 `7cab389` L3 끔 구간 항목 그대로다.
- **G2 (보조, 발광):** LED 다이오드 순방향 평균(같은 구간) ≤ 기존 회로 값. 나빠지지 않아야 한다.

**나빠짐 허용 0 (기존 통과 항목):**
- 비교는 같은 모델·같은 모서리에서 한다.
- "나빠짐"은 시뮬레이터 상대 허용오차(reltol 1e-3)를 넘는 변화로 정의한다.

| # | 항목 | 모서리 | 조건 |
|---|---|---|---|
| N1 | 효율 η = (LED 소비 전력) ÷ (12V_IR 입력 전력), 100 % 켬 | typ | η_후보 ≥ η_기존 − 0.1 %p |
| N2 | LED 다이오드 평균 전류 (L1 최소/최대 모서리) | imin, imax | L1 한계 안 (≥ 0.90 / ≤ 1.10 A) **그리고** 기존 대비 변화 ≤ 0.1 % |
| N3 | LED 피크 · 인덕터 피크 · 스위칭 주파수 · tON · 듀티 · 리플 (L1 항목) | L1 모서리 | 모두 L1 한계 안 |
| N4 | PWM 25 % 실효 켬 비율 (켬 응답) | worst_in | ≤ 0.255 **그리고** ≥ 기존 − 0.005 (응답이 느려지지 않음) |
| N5 | 12V_IR 20 µs 이동 평균 최댓값 (켬 순간 포함) | worst_in, A+B | ≤ 1.86 A **그리고** ≤ 기존 × 1.001 |
| N6 | 12V_IR 평균 (L2) | worst_in, A+B | ≤ 기존 × 1.001 |

- L4~L10(DRV8837 · CAM_1V8 · 센서 레일 · I2C · 리셋)은 후보가 바꾸지 않는 회로라 영향이 없다. 고른 안이 있으면 run.py 전체를 다시 돌려 그대로인지 확인한다.

**고르는 규칙:**
- G1 · G2 · N1~N6을 모두 만족하는 후보 가운데 부품 수가 적은 것을 고른다. 같으면 N1 손실이 작은 것을 고른다.
- 그런 후보가 없으면 **불합격 기록 + 근거 유지**로 끝낸다. 이 경우 후보별 수치를 근거로 남긴다.
